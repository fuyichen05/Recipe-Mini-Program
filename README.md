# 家庭菜谱记录 · 微信小程序

记录家人做成功、值得复刻的菜品，核心是**配方比例**（自由文本，自己写比例即可）。
家人通过**体验版**共同使用同一份云开发数据：一个人添加/修改/删除，其他人打开小程序即可看到最新内容。

- 框架：微信小程序**原生框架**（WXML + WXSS + JavaScript）
- 后端：**微信云开发**（云数据库 + 云存储），纯客户端直连，**无需编写任何云函数**
- 不依赖任何外部后端或海外服务

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 菜品记录 | 菜名（必填）、封面图（必填，拍照/相册）、配方自由文本（必填）、备注（可选） |
| 分类 | 预设五类：早餐 / 正餐 / 甜点 / 汤 / 其他，添加时必选 |
| 收藏 | 列表卡片星标、详情页均可一键收藏/取消 |
| 列表排序 | 收藏的在前，其余按菜名拼音/字母升序（客户端排序） |
| 编辑/删除 | 详情页操作，**所有家庭成员对任何菜品都有编辑删除权限** |
| 数据共享 | 全家共用一个云数据库，页面 onShow / 下拉刷新即拉取最新 |

## 一、首次运行步骤（约 10 分钟）

### 1. 准备 AppID 并导入项目

1. 如果你还没有小程序账号，到 [mp.weixin.qq.com](https://mp.weixin.qq.com) 注册一个小程序（**个人主体即可，免费**），在「设置 → 基本设置 → 账号信息」里可以看到 **AppID**。
2. 打开**微信开发者工具** → 「导入项目」→ 选择本目录 → AppID 填你自己的（会自动覆盖 `project.config.json` 里的占位值；也可以直接编辑 `project.config.json` 的 `"appid"` 字段）。
   > 注意：不能用「测试号/游客模式」，云开发必须使用真实注册的 AppID。

### 2. 开通云开发，获取环境 ID

1. 在微信开发者工具顶部工具栏点击「**云开发**」→ 开通云开发，选择**免费的基础套餐**，创建一个环境（名字随意，如 `family-recipes`）。
2. 创建完成后，云开发控制台**左上角**会显示「环境 ID」，形如 `cloud1-3g1axxxxxxxx`，复制它。

### 3. 在代码里填入环境 ID

打开 `app.js`，把环境 ID 填到第一处配置里：

```js
const CLOUD_ENV_ID = 'cloud1-3g1axxxxxxxx' // ← 换成你的环境 ID
```

（如果你只创建过一个环境，留空 `''` 也可以，会自动使用默认环境。）

### 4. 创建数据库集合并配置安全规则 ⚠️（最关键的一步）

1. 云开发控制台 → 「数据库」→ 「+」新建集合，名称必须是 **`recipes`**。
2. 点击进入 `recipes` 集合 → 「**权限设置**」→ 选择「**自定义安全规则**」，填入：

   ```json
   {
     "read": true,
     "write": true
   }
   ```

   > **为什么必须用自定义安全规则？** 基础权限的四个选项都做不到「所有人可读可写」：
   > 「所有人可读、仅创建者可写」会让家人**无法编辑/删除别人添加的菜品**。
   > 自定义安全规则 `{"read": true, "write": true}` 表示所有用户可读、所有用户可写，
   > 这正是"全家人互相同步、互相编辑"所需要的。

字段结构（代码会自动写入，无需手动建字段）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| name | string | 菜名（必填） |
| category | string | 分类：早餐/正餐/甜点/汤/其他（必填） |
| coverImageFileID | string | 云存储文件 ID（必填） |
| recipeContent | string | 配方自由文本（必填） |
| note | string | 备注/心得（可选） |
| isFavorite | boolean | 是否收藏，默认 false |
| createdAt / updatedAt | Date | 创建/更新时间（服务端时间） |

### 5. 编译运行

回到开发者工具点击「编译」，即可在模拟器中运行。用真机调试时请让手机和电脑在同一网络，或直接用下一步的「预览/体验版」。

### 云存储说明（无需任何配置）

封面图通过 `wx.cloud.uploadFile` 自动上传到云存储的 `covers/` 目录，**云存储不需要开通任何额外服务或做任何配置**；云文件 ID（`cloud://...`）可直接绑定到 `<image>` 组件的 `src` 显示。删除菜品时会调用 `wx.cloud.deleteFile` 同步清理封面文件。基础套餐的存储容量对家庭使用绰绰有余。

## 二、邀请家人一起用（体验版，长期免费）

### 1. 添加体验成员

1. 登录 [mp.weixin.qq.com](https://mp.weixin.qq.com) 小程序管理后台。
2. 「**管理 → 成员管理 → 体验成员**」→ 「添加体验成员」，输入家人的微信号（可搜索或扫码邀请）。
3. 体验成员上限 **15 人**，家庭使用完全够。

### 2. 生成体验版二维码

1. 在微信开发者工具右上角点击「**上传**」，填写版本号（如 `1.0.0`）和备注，确认上传。
2. 回到小程序管理后台 → 「**管理 → 版本管理 → 开发版本**」，找到刚上传的版本。
3. 点击该版本右侧的「**选为体验版**」。
4. 之后在「体验版本」卡片里点击「**体验版二维码**」，把二维码发给家人微信扫码即可打开使用（首次需授权）。

> 也可以用开发者工具的「预览」二维码，但预览码有时效，**体验版二维码是长期有效的**，推荐用体验版。

### ⚠️ 不要发布上线

**本小程序不需要发布上线，也不建议发布：** 免费云环境在小程序**未发布上线**阶段可以一直免费使用；一旦小程序发布上线，免费云环境的试用配额会在约 15 天后到期，需要付费续费。
只用**体验版**即可长期免费，家人以「体验成员」身份正常使用所有功能。

## 三、常见问题

| 现象 | 原因与解决 |
| --- | --- |
| 报错 `invalid scope` / 云开发不可用 | 用了游客模式或测试号。必须使用真实注册的 AppID，并在开发者工具中开通云开发。 |
| 报错 `env check invalid` / `-501016` | `app.js` 里的环境 ID 填错了，到云开发控制台左上角核对。 |
| 家人添加/编辑时提示无权限（`-502003` 等） | `recipes` 集合权限没配好。按上面步骤改成「自定义安全规则」`{"read": true, "write": true}`。 |
| 列表能读到自己加的菜，但看不到家人加的 | 同上，是权限规则问题，改完立即生效，无需改代码。 |
| 图片不显示 | 确认图片是本环境上传的 fileID；如果换过云环境，旧环境的 fileID 无法在新环境显示。 |
| 家人扫码打不开体验版 | 对方还没被添加为「体验成员」，或添加后未重新扫码。 |

## 四、日常使用说明

- **添加菜品**：底部 Tab「添加」→ 填菜名、选分类、选封面图（拍照或相册）、写配方 → 保存。
- **配方写法自由**：`生抽:老抽:糖 = 2:1:1`、`五花肉500g、生抽2勺` 都可以，怎么顺手怎么写。
- **收藏**：卡片右上角星标或详情页「收藏」按钮；列表中收藏的自动排到前面。
- **同步**：任何页面切换（onShow）或下拉刷新都会拉取最新数据，家人的改动即时可见。
- **编辑/删除**：详情页底部按钮；删除会同时清理云存储里的封面图。
